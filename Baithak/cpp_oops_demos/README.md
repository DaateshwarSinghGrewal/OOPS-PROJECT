# C++ OOPS demos

`baithak_oops.cpp` is a compact Baithak-themed example for UN C302 review. It demonstrates overloaded functions, an overloaded equality operator, multiple inheritance, abstract interfaces, virtual dispatch and destruction, method overriding, a function template, `new`/`delete` plus `unique_ptr`, exception handling, file input/output, and formatted output.

Build and run with a C++17 compiler:

```sh
g++ -std=c++17 -Wall -Wextra -pedantic baithak_oops.cpp -o baithak_oops
./baithak_oops
```

The program writes `reservation.txt` in its current working directory.
